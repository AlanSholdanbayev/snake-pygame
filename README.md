# Snake (pygame)

Простой проект на Python + pygame: классическая змейка.

Требования

- Python 3.8+
- pygame

Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Запуск

```bash
python3 main.py
```

Управление

- Стрелки или WASD — движение
- R — перезапуск после Game Over
- Q или ESC — выйти

Если игра не запускается и пишет, что не найден pygame, выполните:

```bash
pip install pygame
```
